
## 一、如何打开/关闭大盘过滤（维度B）

核心开关是 `ENABLE_MARKET_FILTER`，有三种控制方式：

### 方式 1：`-o` 单字段覆盖（最直接，不改配置文件）

```bash
# 打开
uv run python services/calc_indicators/main.py 601899 -o ENABLE_MARKET_FILTER=true

# 关闭
uv run python services/calc_indicators/main.py 600519 -o ENABLE_MARKET_FILTER=false
```

### 方式 2：`-p` 配置档（预设好的组合，一键切换）

| 配置档 | `ENABLE_MARKET_FILTER` | 大盘涨跌幅下限 | 说明 |
|--------|----------------------|--------------|------|
| `default` | `False` | — | 不看大盘，纯个股动量 |
| `short_term` | **`True`** | `-0.5%` | 超短线强制过滤，大盘跌 >0.5% 就一票否决 |
| `swing` | **`True`** | `-1.0%` | 波段，容忍 1% 跌幅但防股灾 |
| `long_term` | **`False`** | — | 长线价投，跌了反而便宜 |
| 其余（high_vol / conservative / trend / aggressive_short / steady_short / ultra_short） | `False`（继承 default） | — | 不看大盘 |

```bash
# 打开（超短线级别过滤）
uv run python services/calc_indicators/main.py 600519 -p short_term

# 打开（波段级别过滤）
uv run python services/calc_indicators/main.py 600519 -p swing

# 关闭
uv run python services/calc_indicators/main.py 600519 -p long_term
```

### 方式 3：配置档叠加（`-p` 可重复，后面覆盖前面的显式字段）

```bash
# 激进短线 + 大盘过滤叠加
uv run python services/calc_indicators/main.py 600519 -p aggressive_short -p short_term

# 超短线止盈止损 + 大盘过滤叠加
uv run python services/calc_indicators/main.py 600519 -p ultra_short -p short_term
```

### 大盘过滤开启后的行为

参见 [main.py#L452-L613](file:///Users/a801/Linda/Work/project/gupiao-assistant/trading_lab/services/calc_indicators/main.py#L452-L613) `check_dimension_b`：

1. **拉取上证综指**（`sh000001`）近 30 日日线
2. **条件1 趋势**：指数收盘 ≥ MA20 → 不满足 = 环境偏空
3. **条件2 涨跌幅**：今日涨跌 ≥ `-0.5%` → 不满足 = 逆势风险大
4. **不硬拦截**：个股 MACD/RSI/放量照常计算并输出，但 `passed = stock_passed AND market_passed`
5. 大盘不通过但个股有信号时，输出 `ℹ️ 个股有动量信号，但大盘环境不佳，建议观望`

## 二、合理参数组合与场景

### 场景 1：日常快速筛查（最常用）

```bash
uv run python services/calc_indicators/main.py 600519
```
- 配置：`default`，大盘过滤关
- 适用：震荡市日常看票，只看个股结构+动量+赔率

### 场景 2：超短线 + 大盘过滤（职业纪律）

```bash
uv run python services/calc_indicators/main.py 600519 -p aggressive_short -p short_term -v
```
- 配置：`aggressive_short`（MA5 精准踩点，0.3% 偏离）+ `short_term`（强制大盘过滤）
- `-v`：打印详细排查日志
- 适用：日内/超短线，大盘暴跌时不出手，泥沙俱下时保命

### 场景 3：波段操作 + 宽松大盘过滤

```bash
uv run python services/calc_indicators/main.py 600519 -p steady_short -p swing -r --open
```
- 配置：`steady_short`（MA5/MA10 双均线确认）+ `swing`（大盘容忍 1% 跌幅）
- `-r --open`：生成 K 线可视化报告并自动打开
- 适用：持仓 3-10 天的波段，可忍受短期回调但防股灾

### 场景 4：长线价投 + 关闭大盘 + 保守仓位

```bash
uv run python services/calc_indicators/main.py 600519 -p conservative -p long_term
```
- 配置：`conservative`（RSI 28 深度超卖 + 盈亏比 2.5）+ `long_term`（关闭大盘过滤）
- 适用：跌了反而便宜，看内在价值，不择时

### 场景 5：急跌反弹 + 高波动 + 轻仓

```bash
uv run python services/calc_indicators/main.py 600519 -p high_vol -o ENABLE_MARKET_FILTER=true -v
```
- 配置：`high_vol`（ATR 动态止损 2.0 倍 + RSI 25 + 仓位 0.8%）+ 手动开大盘过滤
- 适用：市场恐慌性急跌后博反弹，止损宽防毛刺，轻仓试错

### 场景 6：趋势跟随 + 让利润奔跑

```bash
uv run python services/calc_indicators/main.py 600519 -p trend -r --open --name 贵州茅台
```
- 配置：`trend`（突破窗口 30 天 + 止盈 ATR 5 倍追踪）
- 适用：单边上涨行情，突破大级别阻力后持有，止盈用 ATR 追踪

### 场景 7：超短线紧止损 + 可视化

```bash
uv run python services/calc_indicators/main.py 600519 -p ultra_short -p short_term -r --open --skip-all-fail
```
- 配置：`ultra_short`（ATR 1.0 倍紧止损 + 10 日高压基准）+ `short_term`（大盘过滤）
- `--skip-all-fail`：三维度全不通过时跳过 PNG 生成（省时间）
- 适用：日内打板/超短线，紧止损快速认错

### 场景 8：两只股票对比

```bash
uv run python services/calc_indicators/main.py 600519 -c 000858 -p aggressive_short -p short_term -r --name 贵州茅台,五粮液
```
- `-c 000858`：对比模式，同时评估两只
- `-r`：生成对比图（K 线并排 + 维度对比）
- `--name`：逗号分隔两只名称
- 适用：二选一，同板块 PK 选更强标的

### 场景 9：临时微调单个参数

```bash
# 只调盈亏比门槛到 1.5，其余用 default
uv run python services/calc_indicators/main.py 600519 -o MIN_RR_RATIO=1.5

# 只调回踩偏离度到 0.8%
uv run python services/calc_indicators/main.py 600519 -o PULLBACK_MAX_DEVIATION=0.008

# 只换基准指数到沪深 300
uv run python services/calc_indicators/main.py 600519 -o ENABLE_MARKET_FILTER=true -o BENCHMARK_INDEX=sz399300
```

### 场景 10：确认最终生效配置

```bash
uv run python services/calc_indicators/main.py 600519 -p aggressive_short -p short_term -o MIN_RR_RATIO=1.5 --show-config
```
- `--show-config`：运行前打印全量字段 + 每个字段来源（哪个 profile / 哪个 override）
- 适用：叠加多 profile + 多 override 后，确认最终参数没搞错
