# 交易记录格式（观察期用）

一张表，17 列。**每天收盘后填"开仓"部分，结局明确后回填"出场"部分。**

> **不用真买也完全适用。** 这是"纸面观察"，反而更省事：
> 无滑点、无情绪干扰、可批量看票、样本积累更快。
> 唯一要求：**同一批次观察期内，规则不许中途改**（详见文末"纸面观察的注意事项"）。

新建一个文件开始记（别改模板本身）：

```bash
cp services/calc_indicators/交易记录模板.csv 我的交易记录.csv
```

## 怎么填（按顺序，只 4 步）

### 第 1 步：从工具输出抄 5 个数

跑 `uv run services/calc_indicators/main.py 600519`，把这几项抄进来：

| 列 | 从哪来 | 示例 |
| --- | --- | --- |
| `入场价` | 输出「当前价」 | 1251.00 |
| `止损价` | 输出「支撑位(止损)」 | 1228.43 |
| `止盈价` | 输出「压力位(止盈)」 | 1338.86 |
| `盈亏比` | 输出「盈亏比」 | 3.84 |
| `RSI` | 输出「维度B」里的 RSI 值 | 36.5 |

### 第 2 步：自己填 4 个判断项

| 列 | 取值 | 说明 |
| --- | --- | --- |
| `记录日期` | `YYYY-MM-DD` | |
| `代码` / `名称` | | |
| **`入场类型`** | **`突破` / `回踩` / `仅B`** | ⚠️ **最重要的一列**，见下 |
| `市场状态` | 输出「维度E → 市场状态」，如 `TREND_UP` | |
| `信号维度` | `A` / `B` / `A+B` | 哪个维度通过了 |
| `状态` | `持仓中` | 未平仓就写这个 |

### 第 3 步：平仓当天回填 4 列

| 列 | 取值 |
| --- | --- |
| `状态` | `已平` |
| `出场日` | `YYYY-MM-DD` |
| `出场价` | 实际成交价 |
| `出场原因` | `止损` / `止盈` / `手动` / `时间止损` |

### 第 4 步：只在被止损时，回填 1 列

| 列 | 取值 |
| --- | --- |
| **`被扫后3日反弹`** | `是` / `否` |

**判断标准**：被止损后 3 个交易日内，收盘价是否回到你的止损价之上。
- `是` → 止损设在噪声里（止损太紧）
- `否` → 真的走坏了（止损合理）

## 为什么 `入场类型` 是最重要的一列

回测（300 只 × 10 年）显示：

| 组合 | 10日收益 | 结论 |
| --- | --- | --- |
| 只用 B（`A❌ B✅`） | **+0.25%** | 唯一为正 |
| 只用 A（`A✅ B❌`） | **−0.22%** | 为负 |
| A 和 B 同时 | **−1.79%** | 最差 |

**所以"突破"单是重点怀疑对象。** 你需要用**自己的实盘**验证它 —— 几周后拆开看：
- `突破` 的胜率 vs `回踩` 的胜率
- 哪一类该继续用、哪一类该放弃

这比调任何阈值都有信息量，因为它是你自己的数据。

## 为什么不记每日价格

只记"开仓 4 + 平仓 4 + 反弹 1"，
**共同9 列是你要手填的**，其余（代码/名称/日期）是抄的或自动的。

不要每天记浮盈浮亏 —— 那会让记录变成负担，坚持不下来。**关键是那 3 个判断项**：
`入场类型`、`出场原因`、`被扫后3日反弹`。

## 记满 3~4 周后能回答什么

| 问题 | 用哪几列 |
| --- | --- |
| 突破单是不是真的更差？ | `入场类型` + `出场原因` + `盈亏比` |
| `near_low` 止损是不是太紧？ | `被扫后3日反弹` 的 `是` 占比（>50% 就是太紧） |
| `MIN_RR_RATIO=3.0` 是否过严？ | 对照 `-o MIN_RR_RATIO=2.0` 跑同一批票，看通过率差异 |
| 哪种市场状态下信号靠谱？ | `市场状态` 分组统计 |
| 该用哪个维度？ | `信号维度` 分组统计 |

记满后把这个 CSV 发我，我做成 `--monitor` 命令（自动统计上面这些），
并按你的实际字段定 schema —— **这也是我暂时不写 `--monitor` 的原因**，
先确认你实际愿意记哪些列。

## 纸面观察（不真买）的注意事项

不用真钱，但要把"假设"填成"事实"，否则统计出来的数字没有意义。

### 1. 三个"假设值"按规则填，不按理想价填

| 列 | 别填 | 应该填 |
| --- | --- | --- |
| `入场价` | "那天最低点买入" | **工具输出的「当前价」**（即信号当日收盘价） |
| `出场价` | 事后挑的好价格 | **触发止损/止盈的那个价位**（按规则） |
| `出场原因` | — | 明确 `止损` / `止盈` / `时间止损` / `手动(超时)` |

**关键：`出场价` 填止损价或止盈价本身，不是当天的收盘价。**
因为纸面观察没有滑点，触发即成交，这是最干净的假设。

### 2. `被扫后3日反弹` 仍然必须填

这一列是全部记录里**最有价值**的，纸面观察下更容易填对（不用管真实持仓）：

> 被止损后 3 个交易日内，**收盘价是否回到止损价之上**。

- `是` → 止损设在噪声里
- `否` → 真的走坏了

### 3. 收盘价入场的偏移（纸面观察特有的偏差）

工具在**收盘后**运行，用的是当日收盘价。现实里你最早只能**次日开盘**进。
→ 建议加一列 `次日开盘价` 记下来，几周后能看出这个偏移有多大影响。

如果不想加列，至少在 `备注` 里偶尔记一下，心里有数。

### 4. 同一批次不许改规则 ⚠️

这是纸面观察最容易犯的错：**看到连续被扫就把 `STOP_MODE` 换成 `swing_atr`** ——
一旦中途换规则，前后数据就不可比，这个批次作废。

正确做法：
- **一批固定一套参数**，记满 3~4 周
- 想试另一套 → **另起一批**（新建一个 CSV，如 `我的记录_swing_atr.csv`）
- 两批对比，而不是混在一起

### 5. 每天固定时间跑

建议**收盘后固定时间**（如 15:30 后），且**用同一套命令**：

```bash
cp services/calc_indicators/交易记录模板.csv 我的记录_batch1.csv
uv run services/calc_indicators/main.py 600519
```

### 6. 观察多少只合适

- 太少（<10 只）→ 几周也攒不到足够样本
- 太多 → 记录变成负担

建议 **10~20 只自选股**，每天跑一遍（约 1~2 分钟），几周能积累 **50~150 条信号**。
