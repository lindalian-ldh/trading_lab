Trading Lab Services 总览

个人 A 股量化辅助决策服务集合 · 宏观 / 大盘 / 板块 / 个股 四层复盘工具链

所有命令在 trading_lab 目录下执行，首次使用先 uv sync 安装依赖。各服务遵循「argparse CLI + 跑完即退」批处理模式。

1各服务目的与功能

共 9 个独立服务，按分析层级分为五大类：宏观、大盘、板块、个股、辅助工具。

宏观层
macro-data-service

宏观数据采集

从 akshare 与 FRED 抓取中国 / 美国 / 商品的 CPI、PPI、GDP、M2、LPR、失业率、国债收益率、贵金属等指标，标准化为统一 JSON 模型后写入 SQLite 或 Parquet。增量去重 + 300 秒超时保护，单指标失败不阻断批量。

存储：data/trading.db · macro_data / macro_us_data 表
宏观层
macro-charts

宏观指标可视化

与采集模块解耦，仅依赖数据表。数据驱动读取指标名称 / 单位，Plotly 多 Y 轴折线图，最多 3 指标 3 轴对比。输出 JSON（终端）或自包含 HTML，Viridis 色盲友好色板。

输出：data/reports/charts/{indicator}.html
大盘层
alarming_monitor

大盘预警 + 板块轮动

整合三大核心：5 大原子风险信号（S1 成交额 / S2 放量不涨 / S3 涨跌家数 / S4 高股息逆势 / S5 成长破位）+ ADX 市场状态动态阈值 + RRG 板块轮动四象限与 5 维评分卡。参考日数据驱动自动选今日 / 昨日，输出 Markdown 全景报告与 CSV 历史。

扩展：连板龙头（linkban）+ 两融杠杆（margin）子模块
板块层
bankuai-service

板块扫描与龙头梯队

基于 zzshare 接口扫描 A 股板块热度排名（概念 / 题材 / 行业），对热门与冷门板块识别三级龙头梯队：领涨龙 / 中军 / 补涨潜力。纯信号系统，单板块失败不影响整体，30 次/分钟限频自动退避。

输出：data/reports/bankuai/bankuai_{date}_{plate}.json
个股层
calc_indicators

开仓三维度筛查

输入股票代码，从结构（回踩均线）、动量（MACD/RSI/大盘过滤）、赔率（盈亏比/止损止盈）三维度判断是否值得开仓。10 个配置档可叠加，支持单字段 override，生成 K线+MACD+RSI+止损止盈 PNG 报告，含两只股票对比模式。

输出：data/reports/report_{symbol}_{date}.png
个股层
yanbao-info

券商研报摘要

输入股票代码，自动获取最近券商研报，下载 PDF 并用 pdfplumber 解析，通过关键词+正则提取评级 / 目标价 / 盈利预测 / 催化剂 / 风险，结合一致预期与当前股价产出短线博弈信号判断，输出 JSON + Markdown 摘要。

缓存：data/yanbao/{pdfs,cache,history,reports}/
个股层
sell_monitor

动态止盈止损监控

克服「处置效应」，将卖出完全机械化。三层卖出机制：硬止损（保命线）/ 动态移动止盈（阶梯抬升网格分批）/ 时间止损（效率线）。进场即锁定所有规则，每日收盘后输出 hold / sell_partial / sell_all 信号，支持三档配置。

存储：data/trading.db · positions 表 + CSV 日志
辅助工具
crawler_news

财经新闻采集

抓取 5 个 AkShare 财经接口（财联社 / 新浪 / 巨潮 / 东财泛 / 东财个股），自动标注股票代码，落盘 JSON Lines，按日期范围生成 Markdown / HTML 简报，含国内外区域分布与被提及最多的股票 Top5。

输出：data/reports/news/{YYYY-MM}/
辅助工具
generate_report

每日复盘报告

基于 Jinja2 模板渲染单只标的的复盘摘要：最新收盘 / MA5 / MA20 / RSI14 / MACD + AI 评分。读取已计算指标的 K 线，输出纯文本报告。轻量级工具，可纳入 run_all.py 流水线。

输出：data/reports/report_{date}.txt

2四层完整复盘流程

从宏观到个股，依次调用以下命令可完成一个完整的盘后复盘。建议收盘后 17:30 执行（数据已更新）。

第 1 层宏观背景判断
判断当前国内外宏观环境（通胀 / 流动性 / 利率 / 周期），为仓位基调定方向。
# 1.1 抓取中国核心宏观指标最近 36 期
uv run services/macro-data-service/main.py --indicator cpi_cn,ppi_cn,m2_cn --recent 36

# 1.2 抓取美国 10Y 国债 + 黄金 + 美元指数
uv run services/macro-data-service/main.py --indicator fred_dgs10,sge_gold,fred_dtwexbgs --recent 60

# 1.3 生成可视化对比图（CPI vs PPI 双轴 / 美债+黄金+美元三轴）
uv run services/macro-charts/main.py --indicator CPI,PPI --output html
uv run services/macro-charts/main.py --table macro_us_data --indicator DGS10,GOLD,DTWEXBGS --output html
第 2 层大盘温度与风险预警
看市场整体风险水位：成交额 / 放量 / 涨跌家数 / 风格切换 + ADX 趋势强度，决定是否降仓。
# 2.1 全流程：5 大预警信号 + ADX 动态阈值 + 板块轮动 + 连板 + 两融
uv run services/alarming_monitor/main.py

# 2.2 查看近 3 个月预警红灯历史（判断是否处于连续预警期）
uv run services/alarming_monitor/main.py --history

# 2.3 极端行情下切保守档提前预警
uv run services/alarming_monitor/main.py --profile conservative
第 3 层板块轮动与龙头识别
从板块层面找主线：RRG 四象限看谁在领涨 / 退潮，三级梯队锁定龙头股，连板看情绪。
# 3.1 仅看板块轮动全景（RRG 四象限 + 5 维评分 + 排名变化）
uv run services/alarming_monitor/main.py --rotation-only

# 3.2 扫描行业板块 Top10/Bottom10 + 三级龙头梯队
uv run services/bankuai-service/main.py --plate-type 行业

# 3.3 看连板龙头与市场温度（晋级率 / 封单金额 / 梯队分布）
uv run services/alarming_monitor/main.py --linkban-only

# 3.4 脚本一键：板块龙头扫描 + 可视化图
./scripts/scan_leaders_chart.sh -p aggressive_short --open
第 4 层个股开仓 / 持仓 / 卖出
从板块龙头池中选标的，做开仓前筛查 + 研报参考 + 新闻跟踪，进场后用 sell_monitor 接管卖出。
# 4.1 个股开仓三维度筛查（生成 PNG 报告并打开）
uv run python services/calc_indicators/main.py 600550 -p aggressive_short -r --open

# 4.2 获取该股券商研报摘要与短线信号
uv run services/yanbao-info/main.py --symbol 600550

# 4.3 跟踪该股相关新闻
uv run python services/crawler_news/main.py crawl --symbol 600550
uv run python services/crawler_news/main.py report --start-date 2026-08-01 --end-date 2026-08-31 --symbol 600550 --format html

# 4.4 开仓即登记持仓（锁定所有卖出规则）
uv run services/sell_monitor/main.py --symbol 600550 --date 2026-08-31 \
    --init --entry-price 10.00 --shares 1000

# 4.5 每日收盘后监控卖出信号
uv run services/sell_monitor/main.py --symbol 600550 --date 2026-08-31
参考日规则：alarming_monitor / sell_monitor / bankuai-service 默认数据驱动选今日 / 昨日。早上运行不带 --date（取昨日），晚上运行加 --date 今日。

4改进方向、局限与人工参与

  • 局限数据源稳定性受限

    全部依赖免费接口（akshare / zzshare / 腾讯 / 新浪 / legu / FRED），无付费 API 兜底。已知问题：akshare stock_news_em 存在 \u 转义 bug 触发 ArrowInvalid；东财历史接口已移除改用腾讯主源；zzshare 免费版限 30 次/分钟。建议：对接一个付费数据源（如 Tushare Pro / Wind）作为高级兜底，或自建行情落库服务。

  • 局限批处理非实时

    所有服务「跑完即退」，无驻留进程。盘中无法实时推送卖出信号，只能盘后一次性扫描。sell_monitor 的移动回撤止损在盘中急跌时存在滞后风险。建议：引入轻量级常驻 scheduler（如 APScheduler）做盘中定时巡检，或对接券商 Level-1 行情 WebSocket。

  • 局限通知渠道单一

    notifier.py 仅实现 ConsoleNotifier，飞书 / 邮件 / 微信为预留扩展点未落地。预警红灯、卖出信号均只能在终端查看，离开电脑即失效。建议：优先实现 FeishuNotifier（飞书机器人 webhook），与现有 Lark 插件联动，实现盘中关键信号手机推送。

  • 局限ETF 数据多源拼接

    alarming_monitor 的 ETF 日线需腾讯主源 + 东财快照补今日 + adata 回退三层拼接，逻辑复杂。腾讯源不含今日数据时需全局 30s 拉取 19 只 ETF 快照，存在单点延迟。建议：统一行情落库到 SQLite，各服务从库读取，解耦数据获取与计算。

  • 局限研报解析依赖正则

    yanbao-info 用关键词+正则提取评级 / 目标价，研报格式不统一时漏提率高。不同券商 PDF 排版差异大，表格提取依赖 pdfplumber 对版式敏感。建议：引入 LLM 抽取（结构化输出），或对接券商官方结构化研报 API。

  • 人工参与买卖决策最终需人确认

    系统是纯信号系统，不直接下单。calc_indicators 给出开仓建议股数，sell_monitor 给出 sell_partial/sell_all，均需交易员手动执行。这是设计意图（防黑天鹅、防程序 bug），但意味着人必须盯终端。建议：对接券商 API（如 QMT/Ptrade）实现半自动（信号 → 一键确认 → 下单）。

  • 人工参与配置档需根据市场状态切换

    alarming_monitor 有 default/conservative/strict 三档，calc_indicators 有 10 档，sell_monitor 有 3 档，均需人工判断市场状态后手动 --profile 切换。系统不会自动识别「现在是震荡市」并切换。建议：基于 ADX / 波动率自动推荐配置档，或接入 alarming_monitor 的市场状态输出驱动下游配置。

  • 人工参与板块轮动 5 维评分需主观解读

    5 维评分卡给出「持有/加仓」「关注建仓」「回避」三档操作参考，但「回避」≠ 一定会跌，只是相对沪深300没有超额收益。是否真的回避、何时建仓、仓位多少，需结合宏观周期、政策面、个人风险偏好综合判断。系统提供的是中期筛选，不是短线择时。

  • 进化跨服务数据闭环未打通

    bankuai-service 扫出的龙头股 → calc_indicators 筛查 → yanbao-info 看研报 → sell_monitor 接管，这条链路目前需手动串接。stock_mapping.json 仅最小种子。建议：实现 run_all.py 的复盘流水线编排，自动把龙头池喂给 calc_indicators 批量筛查，结果沉淀回 stock_mapping。

  • 进化AI 评分待增强

    generate_report 的 AI 评分当前为 Mock=0.5，AIClient.analyze 未真正接入大模型。crawler_news 的事件演化跟踪视图（关键词聚类）未实现。建议：接入真实 LLM 做新闻摘要 + 情绪打分 + 事件演化追踪，与板块轮动信号做相关性分析。

  • 进化回测与绩效归因缺失

    系统有历史预警 CSV、卖出信号 CSV，但缺少回测引擎验证策略有效性。无法回答「过去 3 个月按 5 维评分操作的实际收益如何」「保守档 vs default 档谁更优」。建议：新增 backtest 服务，基于历史信号做策略回测 + 绩效归因（夏普 / 最大回撤 / 胜率）。

核心定位提醒：这套工具是中期板块相对强弱筛选 + 风险预警 + 机械化卖出的辅助决策系统，不是短线择时神器。它帮你「少犯错、不踩雷、纪律执行」，但「买什么、何时买、买多少」的核心判断仍需人结合宏观周期、政策面、行业景气度主动完成。系统的价值在于把人的精力从盯盘、算指标、纠结卖不卖，解放到「想清楚逻辑、做对决策」上。
