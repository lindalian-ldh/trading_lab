# Fupan Report — 招商证券资金流水多维度量化复盘

针对招商证券（或兼容格式）导出的历史资金流水 `.xls/.xlsx` 文件，进行 **成本 / 绩效 / 择时 / 仓位 / 纪律** 五大维度量化复盘，控制台打印格式化报告并落盘 `data/reports/fupan_{date}.txt`。

## 一、五大复盘维度

| 维度 | 模块 | 关键产出 |
| :--- | :--- | :--- |
| 1. 交易成本 | `analyze_cost` | 总交易额(双边)、佣金率(‱)、规费合计、单笔佣金 Top5、佣金率>5‱ 预警 |
| 2. 标的绩效 | `analyze_performance` | 按证券名称汇总买卖、已实现盈亏、盈利贡献榜 / 亏损拖累榜 |
| 3. 买卖点效率 | `analyze_timing` | 加权平均买入/卖出价、价差率、高抛低吸 / 低抛高吸 判定 |
| 4. 资金与仓位 | `analyze_capital` | 每日净流入、前三大重仓(估算市值)、日均买入金额 |
| 5. 纪律总结 | `analyze_discipline` | 买卖笔数比、**真实盈亏比(按完整轮次)**、轮次胜率、已实现vs浮动盈亏分解、综合结论 |

## 二、依赖安装

仅依赖标准数据栈（pandas/numpy + Excel 读取库）：

```bash
# 方式一：uv（项目推荐）
uv sync

# 方式二：pip
pip install pandas numpy openpyxl xlrd
```

- `openpyxl`：读取 `.xlsx`
- `xlrd`：读取老版 `.xls`

## 三、常用命令

```bash
# 基本用法（等价于需求文档中的 python review.py -f 历史资金流水.xls）
python services/fupan-report/main.py -f 历史资金流水.xls

# 通过 uv 运行
uv run services/fupan-report/main.py -f 历史资金流水.xls

# 指定绝对路径
python services/fupan-report/main.py -f /path/to/历史资金流水.xls
```

运行后：
1. 终端直接打印完整复盘报告。
2. 报告同时落盘到 `data/reports/fupan_{YYYYMMDD}.txt`（日期为流水最末成交日）。

## 四、输入列规范

文件须包含以下列头（与招商证券导出一致）。**必需列**缺失会明确报错，如 `缺少关键列：佣金`。

| 列名 | 类型 | 关键说明 |
| :--- | :--- | :--- |
| 证券代码 | String | 标的唯一标识 |
| 证券名称 | String | 自动剔除"天添利/产品申购/产品赎回"等现金理财 |
| 成交日期 | Int/Date | 格式如 20260908 |
| 成价价格 | Float | 每股/每份价格 |
| 成交数量 | Float | 买入为正(+)，卖出为负(-) |
| 发生金额 | Float | 买入为负(-)，卖出为正(+) |
| 剩余数量 | Float | 该标的最新持仓余额 |
| 佣金 | Float | 券商收取费用 |
| 印花税 | Float | 卖出时收取（买入为0） |
| 经手费/证管费/过户费 | Float | 规费明细（可选，缺失按0计） |

## 六、二次开发指引

模块按职责分层，便于扩展（如增加可视化图表、HTML 输出）：

| 文件 | 职责 | 扩展点 |
| :--- | :--- | :--- |
| `config.py` | 阈值与常量 | 改阈值无需动业务代码 |
| `data_loader.py` | 读取与清洗 | 新增券商格式适配、过滤规则 |
| `analyzers.py` | 五大分析器（纯函数） | 每个函数独立可测；新增维度仿照现有签名 `analyze_xxx(df) -> dict` |
| `reporter.py` | 渲染与落盘 | `render_report` 改输出格式；新增 `render_html` 即可输出 HTML |
| `main.py` | 入口编排 | 串接新分析器、调整流程 |

各分析器签名：`analyze_cost(df) / analyze_performance(df) / analyze_timing(df) / analyze_capital(df) / analyze_discipline(df)`，均接收清洗后 `DataFrame`，返回 `dict`。

## 七、注意事项

- **现金理财自动过滤**：证券名称含"天添利/产品申购/产品赎回"的记录会被剔除，报告会显示剔除条数。
- **佣金率预警**：实际佣金率 > 5‱（万分之5）会输出 `⚠️ 警告`。阈值在 `config.py` 的 `COMMISSION_RATE_WARN_BPS` 调整。
- **真实盈亏比按完整轮次计算**：系统按"证券名称"聚合完整交易轮次，**仅清仓标的（剩余数量=0）**计入盈亏比，持仓标的的盈亏计入浮动盈亏不锁定。真实盈亏比 = 已实现总盈利 ÷ 已实现总亏损。这避免了"按卖出笔数算胜率虚高"的会计错误（同一轮建仓的多笔卖出不应拆成多次胜/负）。
- **胜率按轮次**：盈利轮数 ÷ 已清仓轮数。持仓标的未清仓不计入。
- **重仓市值为估算**：按"剩余数量 × 该标的最新成交价"计算，非实时行情价。
- **已实现盈亏口径**：仅统计已卖出部分（卖出收入 - 买入成本），不含浮动盈亏。
