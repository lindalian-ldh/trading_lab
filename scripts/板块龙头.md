# 板块龙头扫描 + 入场指标图

## 简要说明

`scan_leaders_chart.sh` 是一个一键脚本，串联 `bankuai-service` 与 `calc_indicators` 两个服务：

1. **板块扫描**：调用 `bankuai-service` 扫描前 N 个热门板块，提取每个板块的一级领涨龙头（tier1）
2. **未入选标的列表**：打印未入选任何梯队（一级/二级/三级均不满足）的标的，含涨幅/换手/量比
3. **指标图生成**：对每只一级龙头调用 `calc_indicators` 生成入场指标 PNG 图片
   - 内置 `--skip-all-fail`：三维度（A结构/B动量/C赔率）全不通过时自动跳过，不生成图片
   - 只要至少一个维度通过就生成图片

### 产出文件

| 文件 | 说明 |
|------|------|
| `data/reports/bankuai/bankuai_{date}_{plate_type}.json` | 板块扫描报告 |
| `data/reports/{当天日期}-png/report_{股票代码}_{日期}.png` | 入场指标图 |

### 前置条件

- 已在项目根目录执行 `uv sync`
- `.env` 中已配置 `ZZSHARE_TOKEN`
- `uv` 已加入 PATH

## 参数说明

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `-p, --profile <名称>` | 否 | `default` | calc_indicators 配置档，可重复传入叠加。可用值见下表 |
| `--date <YYYY-MM-DD>` | 否 | 昨天 | 板块扫描日期 |
| `--top-n <数量>` | 否 | `3` | 扫描前 N 个热门板块 |
| `--plate-type <类型>` | 否 | `概念` | 板块类型：`概念` / `题材` / `行业` |
| `--open` | 否 | 关 | 生成图片后自动用浏览器打开 |

### 可用配置档（`-p` 参数）

| 配置档 | 说明 | 适用场景 |
|--------|------|----------|
| `default` | 标准配置 | 日常使用 |
| `aggressive_short` | 激进短线 - 精准踩MA5 | 强势行情追涨 |
| `steady_short` | 稳健短线 - MA5/MA10双均线确认 | 短线确认入场 |
| `short_term` | 超短线 - 强制大盘过滤 | 严格大盘环境要求 |
| `swing` | 波段 - 放宽大盘涨跌幅限制 | 波段操作 |
| `trend` | 趋势跟随配置 | 单边行情 |
| `conservative` | 保守配置 | 震荡市/不确定行情 |
| `high_vol` | 高波动配置 | 急跌反弹行情 |
| `long_term` | 长线价投 - 关闭大盘过滤 | 长线布局 |

## 命令清单（覆盖所有场景）

### 1. 默认扫描

前 3 个概念板块，default 配置，扫描昨天数据。

```bash
./scripts/scan_leaders_chart.sh
```

### 2. 指定配置档

前 3 个概念板块，使用激进短线配置。

```bash
./scripts/scan_leaders_chart.sh -p aggressive_short
```

### 3. 叠加配置档

后一个配置覆盖前一个的显式字段，实现"激进短线 + 长线过滤关闭"组合。

```bash
./scripts/scan_leaders_chart.sh -p aggressive_short -p long_term
```

### 4. 指定板块数量

扫描前 5 个热门概念板块。

```bash
./scripts/scan_leaders_chart.sh --top-n 5
```

### 5. 指定日期

扫描指定日期的板块数据（非昨天）。

```bash
./scripts/scan_leaders_chart.sh --date 2026-08-12
```

### 6. 切换板块类型 — 行业板块

扫描行业板块而非概念板块。

```bash
./scripts/scan_leaders_chart.sh --plate-type 行业
```

### 7. 切换板块类型 — 题材板块

```bash
./scripts/scan_leaders_chart.sh --plate-type 题材
```

### 8. 生成后自动打开图片

每张图片生成后自动用浏览器打开。

```bash
./scripts/scan_leaders_chart.sh --open
```

### 9. 保守配置 + 行业板块 + 指定日期

震荡市保守策略，扫描行业板块，指定日期。

```bash
./scripts/scan_leaders_chart.sh -p conservative --plate-type 行业 --date 2026-08-12
```

### 10. 波段配置 + 前 5 板块 + 自动打开

波段操作，扩大扫描范围，生成后自动查看。

```bash
./scripts/scan_leaders_chart.sh -p swing --top-n 5 --open
```

### 11. 趋势跟随 + 题材板块 + 指定日期 + 前 10 板块

单边行情中全面扫描题材龙头。

```bash
./scripts/scan_leaders_chart.sh -p trend --plate-type 题材 --date 2026-08-12 --top-n 10
```

### 12. 高波动配置 + 叠加长线

急跌反弹场景，叠加长线配置关闭大盘过滤。

```bash
./scripts/scan_leaders_chart.sh -p high_vol -p long_term
```

### 13. 超短线 + 行业板块 + 前 5 + 自动打开

严格大盘环境下超短线操作行业龙头。

```bash
./scripts/scan_leaders_chart.sh -p short_term --plate-type 行业 --top-n 5 --open
```

### 14. 全参数组合

配置档叠加 + 板块类型 + 数量 + 日期 + 自动打开，覆盖所有参数。

```bash
./scripts/scan_leaders_chart.sh -p aggressive_short -p long_term --plate-type 行业 --top-n 5 --date 2026-08-12 --open
```

# 指定某个板块
# 仅扫描指定板块的龙头
./scripts/scan_leaders_chart.sh --sectors 半导体,AI算力

# 指定板块 + 配置档 + 自动打开
./scripts/scan_leaders_chart.sh --sectors "半导体,新能源,消费" -p aggressive_short --open
