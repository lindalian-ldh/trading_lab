# 进化路径 —— 什么阶段做什么决定

> 配套 [`每日流程.md`](每日流程.md)：那份讲**每天做什么**，这份讲**每个月看什么、到什么阶段做什么决定**。
> 所有数字都来自本仓库实测，每条结论末尾标注了可复跑的出处。

## 阅读前提：这个系统的能力边界（实测）

| 能力 | 实测证据 | 结论 |
|---|---|---|
| **择时加仓** | 恐慌日买指数持 20 日：全样本 71天/33段 **+2.16pp**（placebo p=0.004）<br>分段：2016-2020 **+0.48pp（p=0.367）** / 2021-2026 **+4.15pp（p=0.000）** | ✅ **唯一被验证的正面用途**，但只在"政策托底"体制里有效 |
| **排雷（生存性否决）** | 加否决后 10 日超额从 **−0.297% → −0.056%**（不显著） | ✅ 保留 |
| **止损纪律** | 期望代价 **−0.29%/笔**，换取 46% 的交易被限制在约 −7% | ✅ 用期望换尾部 |
| **强制记录** | 台账把"感觉"变成可证伪数字 | ✅ **小白最该先建这个** |
| **选股 alpha（A/B/C）** | 可交易域边际 **−0.063%（t=−0.74）**；`A✅B✅` 是**最差**一格 **−1.081pp** | ❌ **不要用它选股** |
| 双因子判读卡 | 只在 signal 池（占样本 **3%**）内成立；最好格 +0.917pp | ⚠️ 只能否决，不能买入 |

**一句话：它最大的价值是阻止你乱买，不是告诉你买什么。唯一被验证的正面用途是择时（什么时候重仓），不是选股（买哪只）。**

## 阶段 0 · 现在 —— 停止在 A/B/C 上投入

**做什么**：不再调 A/B/C 的任何参数。

**依据**：放量阈值扫描 1.5→3.0，效应 **单调恶化**（−0.86pp → −7.35pp），**所有取值都显著为负，没有任何一个能翻正**。
⇒ 这不是"参数没调好"，是**方向错了**。

**别做什么**：不要再跑 `run_abc_factorial.sh`（它的 4 格里 2 格是空操作，见 `scripts/check_override_effect.py`）。

**这是整个路径里最重要的一步。** 在选股边际 = 0 的地方投入的每一小时都是负收益。

## 阶段 1 · 第 1~2 周 —— 建立"记录-对照"闭环

```bash
# 每天收盘后（Step 1~3）
uv run python services/calc_indicators/main.py 600000 --no-weekly   # 看市场状态
uv run python scripts/log_signal_ledger.py --file data/observations/watchlist.txt

# 每周
uv run python scripts/autofill_ledger_bought.py
uv run python scripts/analyze_signal_ledger.py --horizon 10
```

**关键动作**：记录**你根本不会买的**候选票。它们是你唯一的对照组。

**清单必须是三段结构**（用 `scripts/build_watchlist.py` 生成，别手工从成交记录抄）：

| 段 | 来源 | 为什么必需 |
|---|---|---|
| ① 持仓 | 资金流水 | 必须盯 |
| ② 近期成交 | 资金流水 | 连续性 |
| ③ **候选宇宙** | **bankuai 热门板块人气股** | **唯一真正的对照组** |

⚠️ **第一版清单的错误**（2026-10-01，已修正）：它 100% 由成交记录生成，
于是"被标记但没买"只代表"某天没买"，**对照组 = 0** → 永远回答不了"我的判断值多少"。
生成器改成三段结构后，候选宇宙与你是否交易过**完全无关**。

**判据**：**不看结论，只看"样本够不够"。**
前 10 个交易日分析器会硬性打印"交易日不足——不下结论"，**这是设计，不是故障**。

**别做什么**：别改参数；别因为看到"✅ 有强证据"就下单。

## 阶段 2 · 第 1~3 个月 —— 找出你的真实 edge 在哪

**做什么**：只看一张表 —— **你个人的盈亏归因**。

```bash
# ① 一次跑出分账（系统标记 / 你自己挑的 / 台账未覆盖）
uv run python scripts/attribute_pnl.py

# ② 看前瞻收益维度的对照（买 vs 没买）
uv run python scripts/analyze_signal_ledger.py --horizon 10

# ③ 看纪律 KPI（真实盈亏比、轮次胜率、已实现 vs 浮动）
uv run services/fupan-report/main.py -f "$(ls data/reports/历史资金流水_*.xls | sort | tail -1)"
```

**① 的用法**：直接看【三、结论】那一节。

- 若 `系统未标记` 的盈亏 **高于** `系统标记` → **edge 在你的判断** → 系统该降级为检查清单
- 若 `系统标记` 更高 → 系统在帮忙，继续积累样本
- 若全部落在 `台账未覆盖` → **现在还算不出归因**（台账与流水日期不重叠）。
  这不是"系统没用"，去建记录，1~3 个月后重跑

| 维度 | 怎么读 |
|---|---|
| **ETF vs 个股** | 分账看。你已有答案：ETF 6 轮 **+123,973** / 个股 29 轮 **−17,384** |
| **买了的 vs 没买的** | 分析器「买 vs 没买」那一节。`买了的 > 没买的` ⟹ **是你的判断力在赚钱** |
| **系统标记的 vs 你自己加的** | `autofill` 输出里的「流水里有买入、但台账无对应标记」 |

**判据（门槛）**：三个月后必须能回答一句话 ——

> **"我赚的钱，是系统挑出来的，还是我自己挑出来的？"**

**预判**（基于现有证据）：**是你的判断。** 因为你最好的 6 笔全是 ETF，而系统对 ETF 没有可用信息（判读卡样本内 0 只 ETF）。

## 阶段 3 · 第 3~6 个月 —— 在最强的那条线上加深

按阶段 2 的结论三选一：

| 你的 edge 在哪 | 该做什么 | 不该做什么 |
|---|---|---|
| **ETF / 主题判断** | 研究"择时加仓 + 主题持续性"。你已有 12.4 万的证据 | 别把个股判读卡套到 ETF 上 |
| **你自己的判断力** | 把系统**降级为排雷 + 纪律检查清单**，精力放在复盘决策过程 | 别继续指望它选股 |
| **都没有（只是 beta）** | 考虑指数化。承认没有 edge 不丢人，亏给券商才丢人 | 别加杠杆找补 |

## 阶段 4 · 6 个月后 —— 只做一件事：样本外验证

**做什么**：预注册一个假设 → 锁定一段数据不看 → 在锁定段上**只验证一次**。

**判据（两个都要满足）**：
1. `|t| ≥ 1.96`
2. `|效应| ≥ MDE`（分析器会直接打印）

**别做什么**：**别在同一批数据上反复调参。**
这个坑我们这几轮踩过：恐慌择时最初看着是 **+5.6pp**，换指数后缩到 **+1.93pp（p=0.089，不显著）**，最后确认是 **+2.16pp** 且分段差异巨大（前 5 年 ≈0）。

## 三个必踩的歧路（提前警告）

**歧路 1 · 在没用的地方优化**
A/B/C 的选股边际是 0，参数无解（单调反向）。**在这里投入的每一小时都是负收益。**

**歧路 2 · 用回测数字代替自己的账本**
回测（以及系统设计意图）说 `A✅B✅` 是"最强买点"，实测它是**最差一格**（−1.081pp）。
**回测可以骗你，你的账本不会。**

**歧路 3 · 把"观察"变成"找买入理由"**
判读卡说"➖ 证据不足"的意思是**没有意见**，不是"可以考虑"。

## 判据速查（可证伪的门槛）

| 判据 | 阈值 | 来源 |
|---|---|---|
| 分析器是否给结论 | `交易日 ≥ 10` | `analyze_signal_ledger.py` 硬门槛 |
| 一个效应是否可信 | `\|t\| ≥ 1.96` **且** `\|效应\| ≥ MDE` | 80% 功效 / 5% 双尾 |
| 检测 +2pp 优势需要 | **约 149 轮** | 单笔 10 日 SD = 8.72pp |
| 检测 +1pp 优势需要 | 约 597 轮 | 同上 |
| 检测 +0.5pp 优势需要 | 约 2,387 轮 | 同上 |
| 择时的独立事件数 | **33 个恐慌片段**（2016-2026） | `audit_regime_robustness.py` |
| 安慰剂显著性 | `p < 0.05`（片段匹配重采样） | 同上 |

**你当前的体量**：约 31 轮/月（个股）。**在这个样本量上，任何"感觉还可以"都既无法证实、也无法否证。**

## 最后

我见过太多人花两年调一个策略，最后发现**问题不在策略，在于他们从没认真记过自己的账**。

你现在的处境其实很好：**已经有一组真实、指向明确的盈亏数据**（ETF 赚 / 个股亏），手上也有把"感觉"变成数字的工具链。

系统的天花板已经测出来了（选股 ≈ 0，择时 +2~4pp）；**你的天花板还没测过。**
